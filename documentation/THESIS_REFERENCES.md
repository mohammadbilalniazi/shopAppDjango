## Example In-Text Citations

- The system was developed using Django's MVT architecture, which supports rapid development, built-in authentication, ORM-based database access, and secure request handling (Django Software Foundation, 2024; Greenfield & Roy, 2023).
- The payment module follows Stripe's PaymentIntent workflow, allowing card payments to be confirmed securely while tracking payment status in the local database (Stripe, 2024).
- API endpoints were implemented using Django REST Framework, with serializers for data validation and permission checks for organization-based access control (Django REST Framework, 2024).
- Security practices were guided by Django's built-in protections and OWASP recommendations, especially for CSRF, access control, and secure configuration (Django Software Foundation, 2024; OWASP Foundation, 2021).
- PostgreSQL was used to maintain relational consistency through constraints, indexes, and structured transactional records (PostgreSQL Global Development Group, 2024).
